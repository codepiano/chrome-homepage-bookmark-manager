# Local Speed Dial 使用手册

这份手册面向使用者，介绍安装、首次配对、日常操作、备份迁移和故障排查。开发接口单独收录在 [API 使用说明](API.md) 中。

## 1. 安装与首次启动

### 准备环境

请先准备 Chrome、Node.js 22+、Corepack/pnpm。仓库内的启动脚本当前面向 macOS，并依赖 `tmux` 和 `lsof`。

```bash
corepack enable
./scripts/init.sh
pnpm build
./scripts/start.sh
./scripts/status.sh
```

看到本机服务监听 `127.0.0.1:3721` 且健康检查通过后，再安装扩展：

1. 在 Chrome 地址栏打开 `chrome://extensions/`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择 `apps/extension/dist`；
5. 新建一个标签页。

### 连接本机服务

首次打开时，在连接设置里填写：

| 字段 | 默认值或来源 |
| --- | --- |
| API 地址 | `http://127.0.0.1:3721` |
| Token | `data/api-token` 文件内容 |

Token 只用于扩展和本机服务配对，不要把它提交到仓库、截图发布或交给不受信任的程序。

## 2. 建立第一组书签

建议按这个顺序开始：

1. 新建一个文件夹，例如“每日使用”；
2. 在文件夹中添加网址；
3. 等待标题、描述和图标自动补全；
4. 退出整理模式，点击整张卡片打开网站。

只输入 `example.com` 也可以，保存时会自动补成 HTTPS 地址。自动信息获取失败不会影响链接的保存和打开，可以稍后在卡片上重试。

## 3. 浏览、搜索与整理

### 日常浏览

默认模式用于快速打开。卡片上的标题、描述和站点图标帮助识别网站，整张卡片都是主要操作区域。

### 全局搜索

- macOS：按 `⌘ K`；
- Windows/Linux：按 `Ctrl K`；
- 用上下方向键选择结果，按 `Enter` 打开；
- 按 `Escape` 关闭搜索。

### 整理书签

进入“整理书签”后，可以：

- 添加、编辑或删除链接；
- 调整链接和文件夹顺序；
- 管理文件夹及其自动归集规则；
- 为单张卡片设置外观覆盖。

整理完成后退出该模式，可以减少日常浏览时的误操作。

## 4. 自动归集

文件夹可以配置域名规则，每行或用逗号分隔一条：

```text
github.com
*.github.com
docs.example.com
```

规则行为：

- `github.com` 匹配这个准确域名；
- `*.github.com` 匹配根域名和它的子域名；
- 保存规则后会整理已经存在的链接；
- 新增或修改链接时也会自动匹配；
- 一个链接命中多个文件夹时，排在左侧的文件夹优先。

因此，较具体的规则适合放在更靠左的文件夹，通用兜底规则放在后面。

## 5. 浏览历史

扩展获得 Chrome 的历史记录权限后，会分批把既有记录同步到本机数据库，并继续接收新的访问记录。

历史页面支持：

- 按关键词搜索；
- 按日期查看；
- 按注册域名和子域名归组；
- 按最近访问时间排序并继续向下加载；
- 把有价值的历史条目添加到书签文件夹。

Chrome 中删除一条历史记录后，本机库会标记其来源状态，而不会立即抹掉已经归档的本机记录。这使本机历史能够承担后续整理和检索，而不只是 Chrome 历史页的镜像。

如果服务临时离线，扩展会把待同步的访问和删除事件放入本地队列，恢复连接后重试。

## 6. 外观设置

设置面板可调整：

- 浅色、深色或跟随系统；
- 网格列数、卡片宽度和卡片间距；
- 字体、正文大小和强调色；
- 紧凑显示；
- 是否显示描述、点击次数、最近访问和推荐区域。

外观设置保存在本机数据库。单卡片外观仅覆盖该卡片，不会破坏自动获取的网页信息。

## 7. 备份、迁移与恢复

### 完整本机备份

停止服务后复制整个 `data/` 目录，可以保留 SQLite 数据库和配对信息：

```bash
./scripts/stop.sh
```

复制完成后再运行 `./scripts/start.sh`。不要在数据库仍有写入时只复制单个 SQLite 主文件，否则可能遗漏 WAL 中的数据。

### 便携 JSON

JSON 导出适合在不同安装间迁移书签结构。它可以包含文件夹、自动规则、链接、卡片外观和设置，但不会包含：

- Token；
- Chrome 历史；
- 点击记录；
- 网页元信息缓存；
- 本机绝对路径。

导入默认可以使用 `skip` 策略跳过重复 URL；只有明确选择 `update` 或 `create` 时，才会更新现有记录或创建重复项。具体命令见 [API 使用说明](API.md#导入与导出)。

## 8. 更新

拉取新版本后执行：

```bash
pnpm install
pnpm build
./scripts/restart.sh
./scripts/status.sh
```

最后在 `chrome://extensions/` 中找到 Local Speed Dial，点击“重新加载”。只重启本机服务不会更新已经加载的扩展文件。

## 9. 停用与卸载

临时停止本机服务：

```bash
./scripts/stop.sh
```

运行 `./scripts/uninstall.sh` 会停止服务并清理运行状态，但保留 `data/`。随后可在 `chrome://extensions/` 中移除扩展。

如果确认不再需要数据，请先做好备份，再手动删除仓库中的 `data/` 目录。此操作不可通过项目恢复。

## 10. 故障排查

### 新标签页提示连接失败

```bash
./scripts/status.sh
./scripts/restart.sh
tail -n 100 .control-panel/api.log
```

同时检查 API 地址是否为 `http://127.0.0.1:3721`，Token 是否完整复制，是否误带空格或换行。

### 3721 端口被占用

```bash
lsof -nP -iTCP:3721 -sTCP:LISTEN
```

确认占用进程属于哪个程序。不要直接结束不明进程；可以为 Local Speed Dial 设置其他 `PORT`，并在扩展连接设置中填写对应端口。

### 修改代码后扩展界面没有变化

先执行 `pnpm build`，再到 `chrome://extensions/` 重新加载扩展，最后刷新新标签页。

### 标题、描述或图标获取失败

链接本身仍可使用。可以稍后点击重试。某些网站会限制自动请求；如果你的网络需要代理，请在启动服务前配置标准代理环境变量，再重启服务。

### 历史页没有内容

检查扩展详情中的“读取您的浏览记录”权限是否开启，并确认本机服务在线。首次同步量较大时会分批进行，可以稍后再查看。

### 服务离线时只能查看、不能编辑

这是预期行为。离线快照是只读保护层，避免在没有数据权威源时产生冲突；恢复本机服务连接后即可继续编辑。
