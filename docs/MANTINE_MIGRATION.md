# Mantine 迁移记录

核对日期：2026-10-26。此记录说明开发分支的验证结果，不代表正式扩展已发布。

## 依赖兼容性

- Mantine core/hooks 9.7.4 的 peerDependencies 要求 React/React DOM `^19.2.0`，本项目统一为 19.3.1，类型包为 19.3.0。
- Vite 8.3.5 与 React 插件 6.1.2 配套；插件的编译器相关 peers 为可选项，本项目没有启用 React Compiler。
- Vite 支持 Node `^20.19.0 || >=22.12.0`；项目既有要求为 Node 22，本次明确下限为 22.12。
- Vitest 统一为 5.0.5，与 Vite 8 兼容；TypeScript 保持 5.9.3。
- 保留 dnd-kit 和 react-complex-tree；其 React peer 范围允许 React 19，树组件更新至 2.6.4。实际验证了树的渲染和切换，未重新完成所有拖拽手势验收。
- 参考官方 [Vite 接入指南](https://mantine.dev/guides/vite/)，版本与 peer 范围通过 npm registry 核对，并以 pnpm-lock.yaml 固定。

## 公共 UI

入口集中加载 Mantine 基础样式、业务布局样式和公共控件样式。ui.tsx 统一配置 MantineProvider、主题和控件默认值；应用的浅色、深色与系统主题继续由原 Settings 驱动。

输入框、原生下拉框、文本域、复选框、单选框、常用操作按钮、弹窗和通知使用 Mantine。布局、标签、书签卡片和拖拽手柄保留应用样式，通过 UnstyledButton 保留原有事件与 ref。原生 select 的菜单、键盘与 change 事件保持不变，文字右侧预留 40px 箭头空间。

管理弹窗与标签树分别按需加载。最终构建首页 JS 约 435.80 KB（gzip 134.15 KB），标签树约 70.03 KB，弹窗约 186.93 KB。不是与旧版本性能的对照测量，也未测量真实扩展冷启动时间。

设置写入会剔除服务返回的 updatedAt 等只读字段，避免被严格更新接口拒绝；不会回写默认值或修改数据库结构。

## 已完成验证

- 独立 Git worktree：独立安装依赖、构建产物与缓存，没有依赖链接指回原仓库。
- 类型检查、完整构建通过；扩展 4 项测试、服务端 12 项测试通过，contracts 暂无测试用例。
- 浏览器使用新标签页，127.0.0.1:13722 静态生产构建；API 13721、临时 SQLite 数据目录，所有写入限于测试数据。
- 浏览器通过测试专用 Chrome API 替身提供 storage/runtime，并在测试工具中转发同源请求到临时 API。正式代码未添加 HTTP origin 的 CORS 放行。
- 桌面 1440×1000、1280×900，检查浅色/深色、普通与长标签选项、长简介、焦点圈、禁用按钮、复选框、弹窗遮罩与通知层级；截图逐张检查。
- 设置保存并重新读取、新建链接并显示、标签树切换、Tab 焦点位于弹窗内、Esc 关闭及焦点返回触发按钮均通过。最终浏览器控制台无错误。
- 原项目服务在验证前后均为 stopped，未为测试启动、停止或重启正式服务；未操作正式数据和用户现有页面。

## 尚未完成的发布验收

按新功能默认只提交的约定，此次未合并 main、未部署、未重新加载用户已安装的扩展。未测试移动端，也未声称完成真实 Chrome 扩展的后台事件、批量打开、历史同步和拖拽全流程验收。

正式发布需要以 main 的明确提交构建扩展，确认 Chrome 实际加载的产物，再对实际运行版本、连接、关键书签操作及服务健康进行验收。浏览器静态构建验收不能代替这一步。
